# Changelog

Notable changes in this fork of [ashemag/human-atlas](https://github.com/ashemag/human-atlas)
by Maximiliano Silva ([X: @emexs](https://x.com/emexs)).
Live at [human-atlas-workout.vercel.app](https://human-atlas-workout.vercel.app/).

## 2026-09-05 — Fix wger exercise links

- Exercise "Full guide" links now use wger's canonical URL form
  (`/en/exercise/<id>/view/<slug>`); all 32 linked pages verified.

## 2026-09-05 — Studio upgrades: sidebar, hover, dark mode

- Detail sidebar rebuilt as a custom resizable panel: 540px default on desktop,
  drag to resize between 360px and 40% of the viewport, smooth open/close,
  keyboard focus on open, Escape to close.
- Desktop hover preview: hovering a muscle highlights it and shows its name
  at the top with a click-to-expand invitation (fades in/out).
- Dark mode with system-setting default, persisted toggle, and a dimmed 3D scene.

## 2026-09-05 — Localization and video

- Switchable English / Argentine Spanish UI (flag dropdown, browser-language
  default, saved preference): chrome, system names, explanations, and all
  workout content translated with voseo.
- YouTube video button on every exercise and stretch.
- Headings now read "How to workout this muscle" / "How to stretch this muscle".

## 2026-09-05 — Fitness guidance

- Workout guides for every muscle: curated exercises (sets, cues, equipment)
  across 23 muscle groups, with an honest "not a gym muscle" note for eyes,
  tongue, larynx, and heart tissue.
- Free-licensed exercise illustrations from the wger database, linked to full guides.
- Stretching guidance for every trainable muscle, plus bodyweight-only tips
  for neck, pelvic floor, and breathing muscles.
- "Workout" layer preset (muscles, skeleton, and connective tissue only).
- Floor platform toggle.
- Fork credit (author + X handle) in the About panel.
- README documents the fork origin and added features.
